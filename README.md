# DevSummarize

DevSummarize — quick TL;DRs for developer docs, READMEs, and StackOverflow.
Everything runs locally in your browser (no server, no data leaves your machine).

## Features
- Summarize selected text or the main content of any page
- Detects and lists code blocks found on the page
- Runs fully in browser — no API keys required

## How to install (developer / advanced users)
1. Download this repository as ZIP or clone it.
2. In Chrome go to `chrome://extensions/` → enable **Developer mode**.
3. Click **Load unpacked** and choose this repository folder.
4. Use right-click on a selection → *DevSummarize: Summarize selection* or open the popup.

## How to use
- Select text on any page → right-click → DevSummarize: Summarize selection
- Or open the extension and click **Summarize Page / Selection**

## Privacy
All processing happens locally in your browser. No data is sent to remote servers.

## Troubleshooting
- If popup says "No response", make sure the extension is loaded and the page isn't blocked (some extension-restricted pages like Chrome store may not allow content scripts).
